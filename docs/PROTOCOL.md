# 评测口径（PROTOCOL）

> 这份文档回答一个问题：**"98.4% 是怎么算出来的，凭什么信？"**

## 一、评测集构成

| 来源 | 数量 | 说明 |
|---|---|---|
| 真实文档（毕业论文，46 页） | 128 条 | 人工从文档里挑事实写的题（章节、字段、数字、条款） |
| 合成文档（5 份产品/服务文档） | 127 条 | 半自动生成 + 人工改，覆盖定价、SLA、API、安全、工单 |
| 合计 | **255 条** | 去重后；含 25 条**负样本**（资料里没有，应拒答） |

每条用例包含：

```json
{"q": "问题", "keywords": ["答案必须包含的词"], "gold": ["应命中的小节"],
 "refusal": false, "tag": "pricing"}
```

## 二、判定规则（v2，2026-11 升级）

### 可答题：判"对"需要同时满足

1. **没拒答**（不是"资料中没有…"）；
2. **关键词全中**——每个 `keywords` 都在答案里出现；
3. **关键词没被否定**——"不支持私有化部署"里的"私有化部署"不算命中。

`_norm()` 会先做归一化，避免"看着一样但字符串不同"：

| 情况 | 归一化后 |
|---|---|
| `1,990` / `1990` | `1990` |
| `99.9%` / `99.9` | `999`（去百分号） |
| `ＴＬＳ` / `TLS` | `tls` |
| `10 到 15 个工作日` / `10到15个工作日` | 一致 |

### 拒答题：判"对"需要

答案开头 40 字内出现"资料中没有…"这类拒答表述。

### 这个规则**判不了**什么（必须承认）

- **语义正确但用词不同**：答案说"一零九九零"或换了个说法 → 判错（假阴性）；
- **答案对了但漏了半句**：关键词全中但推理错 → 判对（假阳性）；
- **部分正确**：答对一半、编一半 → 归为"对"（这是最危险的）。

所以还需要人工盲评兜底（见第四节）。

## 三、判定规则升级的影响（实测）

同一批 64 条答案，新旧规则对比：

| 规则 | 正确率 | 翻转 |
|---|---|---|
| v1（只去空格） | 62/64 = 96.9% | — |
| v2（归一化 + 否定词） | 62/64 = 96.9% | **0 条** |

**结论**：在这批数据上，新规则没有改变结果——说明**之前的数字不是靠宽松判定撑起来的**。

但构造用例证明 v2 能挡住两类假阳性：

```
"本产品不支持私有化部署" 含 "私有化部署"
  v1 → 判对（错）    v2 → 判错（对）
```

## 四、人工盲评（可靠性验证）

关键词判定只能证明"包含某些字"，证明不了"答得对"。
所以做盲评：

```bash
python tools/make_blind_review.py --n 30
```

产出 `eval/blind_review.md`：
- 30 条随机样本（seed 固定，可复现）
- 只有问题 + 系统答案，**没有系统判定，也没有标准答案**
- 请 2 位同学独立填"对/错/不该拒答"

`eval/blind_review_key.md` 是内部对照表（含关键词），只给评分的人事后核对用。

**指标**：

- **一致率** = 人工判"对" 且 系统判"对" 的比例 / 总样本
- 一致率 ≥ 85% → 判定口径可信，98.4% 这个数字站得住
- 一致率 < 85% → 说明判定偏松，需要收紧关键词或加语义判定

> 这一步需要你找人做（30 条，约 30 分钟）。做完把两个人的结果发我，我算一致率和
> Cohen's kappa，一并写进 README。

## 五、口径边界（写清楚，面试时主动说）

1. 这个 98.4% **只在这 255 条、这个语料上成立**，换行业语料会掉（见第二十三节泛化测试）；
2. 评测集里有 127 条来自合成文档，真实文档只占一半；
3. 关键词判定是"下限"——它不会把错的判成对的（有了否定词检测后），但会把对的判成错的；
4. 负样本 25 条偏少，拒答能力的高估风险比可答题更大。

## 六、面试怎么讲

> "98.4% 这个数我自己也不完全信，所以我做了三件事：
> 一是把判定规则写清楚——关键词命中 + 否定词检测 + 数字归一化；
> 二是做了新旧规则对比，64 条上 0 翻转，说明这个分数不是靠宽松判定撑起来的；
> 三是生成盲评问卷找人独立打分，算一致率。
> 剩下的风险我也写在文档里：关键词判不了'换个说法'，也判不了'答对一半编一半'。"

**能主动说出评测的失效边界，比报一个漂亮数字可信得多。**
